# Synoptic Site 16S and FTICR analysis
#### This repository contains R and shell scripts used for the bacterial and archaeal community analysis and FTICR-MS analysis (bioinformatics, statistics, visualizations) for the manuscript "Soil microbial ecology and microbiome-metabolite linkages improve understanding of ecosystem states along terrestrial-aquatic interfaces" by Bandopadhyay et al. (https://doi.org/10.1093/femsec/fiag066)
#### Final code used for the manuscript is within folder "Final_analysis".
#### Network analysis code using WGCNA is inlcuded in the "16S-FTICR-integration" subfolder within "Final_analysis" main folder.

#### Manuscript citation: Sreejata Bandopadhyay, Robert E Danczak, Kaizad F Patel, Kathleen R Beilsmith, Pamela B Weisenhorn, Trisha L Spanbauer, Nicholas J Reichart, Michael N Weintraub, Vanessa L Bailey, Soil microbial ecology and microbiome-metabolite linkages improve understanding of ecosystem states along terrestrial-aquatic interfaces, FEMS Microbiology Ecology, 2026;, fiag066, https://doi.org/10.1093/femsec/fiag066

#### Associated data files, as relevant, to reproduce the analysis are uploaded within the "Final_analysis" folder. Other associated files can be found on ESS-DIVE.
